Como publicar no GitHub

  1. Crie um repositorio e envie estes arquivos para a branch principal.
  2. No GitHub, abra Settings.
  3. Entre em Pages.
  4. Em Source, escolha Deploy from a branch.
  5. Selecione a branch main e a pasta /root.
  6. Salve e aguarde a publicacao.

Quando o site estiver ativo, a URL principal do GitHub Pages vai abrir esta pagina inicial, e o botao "Abrir sistema OAB" levara direto para o sistema.
